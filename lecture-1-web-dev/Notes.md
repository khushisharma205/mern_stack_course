 What is Web Development?
Web development is the process of designing, building, and maintaining websites and web applications. It encompasses everything from creating a simple static page to developing complex, data-driven interactive platforms.

Anatomy of a Web Application
A modern web application is typically composed of three core layers:

1. Frontend (Client-Side)
The visual and interactive part that users see and engage with.
Core technologies: HTML (structure), CSS (styling), JavaScript (behaviour), and libraries/frameworks like React.js.

2. Backend (Server-Side)
The “brain” of the application. It handles business logic, authentication, server configuration, API endpoints, and communication with the database.
Common runtimes/frameworks: Node.js with Express.js, Django, Ruby on Rails, etc.

3. Database
Persistent storage for the application’s data.
Types & examples:

Relational – SQL (MySQL, PostgreSQL)

NoSQL – MongoDB (document-oriented)

Full-Stack Developer
A full-stack developer possesses the skills to work on all three layers: Frontend + Backend + Database. They are capable of building an entire web application from scratch, integrating the user interface with server logic and data storage.

MERN Stack
The MERN stack is a popular, JavaScript-centric technology bundle for building full-stack web applications. Its name is an acronym for the four key technologies:

MongoDB – NoSQL database that stores data in flexible, JSON-like documents.

Express.js – Lightweight backend web framework for Node.js, used to build APIs and handle server logic.

React.js – Frontend JavaScript library for creating dynamic, component-based user interfaces.

Node.js – JavaScript runtime that allows developers to run JavaScript on the server.
