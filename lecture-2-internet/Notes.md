What is the Internet?
The Internet is a global network of interconnected computers that communicate using standardized protocols (like TCP/IP). Think of it as a massive “network of networks” that allows devices worldwide to share information and services. It is the physical and logical infrastructure that makes the World Wide Web, email, file transfers, streaming, and countless other online services possible.

Example: When you send a WhatsApp message from your phone in Singapore to a friend in London, the data travels through undersea cables, routers, and satellite links that form part of the Internet.

What is a Web Browser?
A web browser is a software application used to access, retrieve, and display content from the World Wide Web. It translates code (HTML, CSS, JavaScript) into the interactive pages we see and use.

Example: Google Chrome, Mozilla Firefox, Safari, or Microsoft Edge. You type a URL like https://www.example.com, and the browser renders the corresponding website.

Client and Server Model
This is the fundamental architecture of the web, based on a request-response cycle.

Client: A device or application that requests a service or resource.

Server: A powerful computer or software that listens for requests and sends back the appropriate response.

Workflow: The client sends an HTTP request (e.g., “give me the homepage”), the server processes it, and returns an HTTP response (the HTML page, images, data, etc.).

Types of Clients
Any device or software that can initiate a request can be a client:

Hardware: Personal computer (PC), laptop, smartphone, tablet.

Software: A web browser (Chrome), a mobile app (Instagram), a command-line tool (cURL), or even a smart TV app.

Example: Your iPhone (hardware) using the Safari browser (software) is a client that requests and displays online content.

Types of Servers
Servers are categorized by the service they provide:

Web Server: Hosts website files and serves them via HTTP/HTTPS. (e.g., Apache, Nginx serving www.example.com)

Application Server: Runs the backend logic of a web app. (e.g., a Node.js/Express server handling user login)

Database Server: Stores and manages data. (e.g., a MongoDB server hosting a product catalog)

File Server: Stores and shares files over a network. (e.g., a corporate FTP server or Google Drive’s storage backend)

Example: When you upload a photo to a social media app, the image is received by an application server, processed, and then stored on a dedicated file or database server.

World Wide Web (WWW)
Often confused with the Internet, the World Wide Web is an information system built on top of the Internet. It consists of interconnected hypertext documents (web pages) accessed via the HTTP protocol and identified by URLs. The Internet is the highway; the Web is the collection of houses (websites) along that highway.

Example: All websites starting with http:// or https:// (like Wikipedia, YouTube) are part of the World Wide Web. Email, while using the Internet, is not part of the Web.

IP Address
An IP (Internet Protocol) address is a unique numerical label assigned to every device connected to the Internet. It serves two main purposes: identifying the device and providing its location for routing data.

IPv4: Four sets of numbers separated by dots. (e.g., 192.168.1.1, 8.8.8.8 — Google's public DNS)

IPv6: A newer, longer format to accommodate more devices. (e.g., 2001:0db8:85a3:0000:0000:8a2e:0370:7334)
